# Repository guidance

- Keep this repository public and free of credentials, private URLs, real transcripts, customer data, host details, and raw identifiers.
- Keep the skills Codex-native and usable through Garcon without changing Garcon core.
- Do not add startup hooks, transcript readers, durable orchestration state, or vendor-specific model names without a documented use case.
- Preserve clean-room wording. Link to upstream projects for attribution instead of copying their prose or code.
- Run `python3 scripts/validate.py` after changes.

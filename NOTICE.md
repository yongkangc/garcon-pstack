# Notice

garcon-pstack is an independent, clean-room implementation inspired by the public architecture and ideas of:

- [pstack](https://github.com/cursor/plugins/tree/efa2a531985e0a8084d36ff3cf87233be8a9f34b/pstack), by Lauren Tan.
- [pstack-claude](https://github.com/michael-denyer/pstack-claude/tree/273d217aea3c8e0a743bcc31bd99d585e3ddf9c6), by Michael Denyer and upstream contributors.
- [Garcon](https://github.com/cfal/garcon), the intended multi-agent workspace integration.

No pstack or pstack-claude source code or skill prose is included in this repository.
